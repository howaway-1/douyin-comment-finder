# 抖音作品评论查找

在自己的电脑上运行，输入**一个抖音视频或图文作品链接**和**一个目标抖音号或主页链接**，自动检查该作品中是否有目标账号发表的评论，并导出结果。

面向中文用户，无需编写代码，也不需要安装 Codex 或购买 AI 服务。当前项目是**评论查找工具**，没有内置情感分析功能，也不能根据一个账号找出其在全平台发表过的所有评论。

[下载项目 ZIP](https://github.com/howaway-1/douyin-comment-finder/archive/refs/heads/main.zip) · [详细使用说明](docs/USAGE.md) · [常见问题](docs/FAQ.md) · [验证记录](VALIDATION.md)

## 能做什么

- 支持视频、图文作品、带 `modal_id` 的作品链接，以及 `v.douyin.com` 分享短链接。
- 默认评论总数 **不超过 100 条**时，检查一级评论及楼中楼；**超过 100 条**时，先只检查一级评论。阈值可以调整。
- 自动打开作品、加载评论、滚动及重试，无需中途点击“继续检索”。
- 支持保存会话和未登录临时会话；遇到登录或验证时，由你在抖音窗口完成，随后自动恢复。
- 按账号标识核对作者，不依赖昵称；命中结果可导出为 JSON 或 CSV。
- 显示检查范围、是否完成及未完成原因，区分“没找到”和“没查完”。

**能否读取、能读取多少评论，取决于抖音向当前浏览器会话提供的内容。** 工具允许未登录开始检查，但不能保证未登录或登录后一定能读完所有作品的评论。隐藏、删除及平台未返回的评论无法确认。

## 使用前需要准备

| 项目 | 要求 |
| --- | --- |
| 电脑 | 推荐 Windows 10 / 11；当前一键启动方式面向 Windows |
| Node.js | 版本至少为 20；新安装建议选择官方仍受支持的 LTS 版本 |
| 浏览器 | 已安装 Microsoft Edge 或 Google Chrome；也可安装 Playwright Chromium |
| 网络 | 首次安装需要下载依赖；检查时需要能够正常访问抖音网页 |
| 作品和账号 | 一条有效作品链接，以及目标抖音号或完整个人主页链接 |
| 登录与验证 | 平台要求时，在工具打开的浏览器窗口本人完成 |
| 文件权限 | 将项目放在自己可以读写的目录，例如“文档”下的文件夹 |

不要把项目放在压缩包里直接运行。无需填写密码、Cookie、API Key 或配置代理。

## 第一次安装：只做一次

1. [下载项目 ZIP](https://github.com/howaway-1/douyin-comment-finder/archive/refs/heads/main.zip)，先解压。也可以在仓库页面选择 **Code → Download ZIP**。
2. 从 [Node.js 官网](https://nodejs.org/zh-cn/download)安装符合上述要求的版本，安装时保留 npm 组件。
3. 打开解压后的项目文件夹，确认能看到 `Install.cmd`、`Start.cmd` 和 `package.json`。
4. 双击 **`Install.cmd`**，等待下载并安装依赖。窗口出现 `Installation complete` 表示安装成功，然后按任意键关闭。
5. 双击 **`Start.cmd`**，打开本地使用页面。

**后续日常使用只需双击 `Start.cmd`。** 新电脑、重新下载的副本或更新依赖后，需要重新执行安装步骤。`Start.cmd` 本身不会安装依赖。

已经安装 Edge 或 Chrome 时，一般无需额外下载浏览器。如果提示找不到浏览器，在项目文件夹空白处右键选择“在终端中打开”，执行：

```powershell
npx.cmd playwright install chromium
```

习惯使用命令行的用户，也可以在项目目录依次运行：

```powershell
node --version
npm.cmd ci
npm.cmd start
```

然后访问 [本地工具](http://127.0.0.1:8765/)。命令行启动需要保持终端运行。Windows 文档使用 `npm.cmd`，可避免部分 PowerShell 环境拦截 npm 的脚本入口。

## 开始检查

1. 粘贴作品链接，可直接粘贴含链接的抖音分享文字。
2. 填写目标账号，优先使用对方的**完整个人主页链接**；抖音号也可以，昵称不能用于身份确认。
3. 选择“本工具已有会话”或“未登录临时会话”，点击“开始检查”。
4. 工具会打开独立浏览器自动检查。若提示登录或验证，在**这次打开的窗口**完成即可，不需要再点继续。
5. 查看命中评论和覆盖状态，按需导出 CSV 或 JSON。

你在日常 Edge、Chrome 或其他内置浏览器里的登录，不会自动同步到本工具。运行期间不要关闭工具打开的作品窗口。

“检查限制”中默认设置为 **10 分钟、2,000 条、全量阈值 100 条**。等待登录、验证及自动重试都计入运行时限；达到限制会保留已有结果并结束。较大的评论区可能需要调整限制，仍不能保证一次查完。

详细步骤、可接受的链接、设置说明和关闭方法见 [使用说明](docs/USAGE.md)；启动失败、登录后无法读取等问题见 [常见问题](docs/FAQ.md)。

## 怎样理解结果

| 结果 | 含义 |
| --- | --- |
| 找到目标评论 | 至少一条评论的作者标识与目标匹配；其他评论可能仍未查完，继续看覆盖状态 |
| 已检查完但未找到 | 本次选定范围已通过分页和数量核验，未发现匹配；如果范围是“仅一级评论”，楼中楼仍未查 |
| 检查未完成 | 可能达到上限、被手动停止、遇到登录或验证、页面错误、数据缺失或账号标识不足；不能据此判断目标没有评论 |

报告中的 `complete` 和 `coverage.scopeComplete` 表示**本次选定范围**是否完成；只有 `coverage.allCommentsComplete` 才表示一级评论及楼中楼均完成。即便完成，也仅指本次页面实际返回并通过核验的范围，不代表平台所有历史数据。

## 本地数据与使用边界

- 服务只监听本机 `127.0.0.1`，默认端口为 `8765`；不是可直接部署到静态网站的在线服务。
- 浏览器登录状态保存在 `.local/browser/`；最近一次任务输入、进度及结果保存在 `.local/last-job.json`。刷新页面可恢复显示，重启服务不会自动继续之前的扫描。
- “未登录临时会话”关闭后不保留浏览器登录，但任务结果仍会保存在本地。
- **不要上传、发送或公开 `.local/` 目录及带有个人信息的导出报告。** 提交问题时先隐藏账号、评论内容及本机路径等不必要信息。
- 工具会通过浏览器访问抖音，不向 AI 服务发送评论。导出只含目标命中评论及必要检查信息，不是整个评论区的数据备份。
- 请在你有权访问的范围内使用，尊重评论者隐私，并遵守平台条款与适用规则。项目不提供验证码破解、登录绕过、代理轮换或访问权限突破。

## 开发与验证

技术栈为 Node.js、Playwright 和原生网页界面。扫描器监听网页正常加载的评论响应，使用页面滚动和可见的回复展开按钮推进检查；不直接重放签名接口。账号的 `uid`、`sec_uid` 与抖音号分别处理，评论按 `cid` 去重。

```powershell
git clone https://github.com/howaway-1/douyin-comment-finder.git
cd douyin-comment-finder
npm.cmd ci
npm.cmd test
npm.cmd start
```

测试使用合成响应和模拟浏览器，覆盖身份核验、分页完整性、楼中楼、自动恢复、会话隔离及导出等。具体版本的验证范围和限制见 [验证记录](VALIDATION.md)。测试通过不能保证抖音未来页面变化后仍可正常工作。

页面结构、平台访问策略或依赖环境变化都可能影响运行。反馈问题前请先阅读 [常见问题](docs/FAQ.md)，并提供版本、已隐藏个人信息的错误信息和复现步骤。
