# 常见问题与故障排查

[返回项目首页](../README.md) · [详细使用说明](USAGE.md)

## 没有编程基础可以用吗？

可以。先安装 Node.js 和 Edge / Chrome，下载并解压项目，双击 `Install.cmd` 安装依赖，再双击 `Start.cmd`。不需要 Codex、API Key 或 AI 订阅。首次安装需要网络，日常检查需要能打开抖音网页。

## 为什么双击安装或启动失败？

先确认已经解压，文件夹内能看到 `package.json`。安装 Node.js 后重新打开终端，运行 `node --version`，版本至少为 20。出现 `node` 或 `npm` 找不到时，检查 Node.js 安装是否包含 npm 和 PATH 设置。

如提示 `Missing Playwright` 或缺少 Playwright，请重新运行 `Install.cmd`。它与“缺少浏览器”是不同问题。安装时出现网络错误，应先恢复到 npm 软件源的正常网络连接，再重试。

## PowerShell 提示禁止运行 npm.ps1？

使用 `npm.cmd ci`、`npm.cmd start`，或直接使用项目的 `.cmd` 脚本；不需要为此更改系统全局脚本执行策略。

## 提示未找到浏览器程序？

安装 Edge 或 Chrome，或者先在项目目录完成依赖安装，再运行：

```powershell
npx.cmd playwright install chromium
```

首次下载浏览器需要网络和磁盘空间。安装浏览器不能解决 `EPERM`、`EACCES` 这类权限错误。

## 提示 EPERM / EACCES，或浏览器启动被限制？

正常关闭旧服务后，从本机 `Start.cmd` 启动，确认当前运行环境允许启动浏览器子进程。如果是单位电脑的应用限制，请由设备管理员按实际提示检查。不要把权限错误误当成依赖没有安装，也无需直接关闭安全软件。

## 提示浏览器配置目录被占用？

关闭本工具重复打开的检索浏览器及后台服务，再启动一个实例。不要在浏览器仍运行时删除其配置目录。普通日常浏览器使用不同配置，通常无需关闭。

## 本地页面打不开或 8765 端口被占用？

先运行 `Start.cmd`；只打开网页地址不会自动启动服务。如果已有同一工具运行，启动脚本会直接打开现有页面。如果端口被其他程序占用，可在项目目录的 PowerShell 中使用另一个端口：

```powershell
$env:DCF_PORT = '8766'
npm.cmd start
```

然后访问 `http://127.0.0.1:8766/`，保持终端运行。端口必须在 1024–65535 之间，且没有被其他程序占用。关闭服务时也要使用相同端口。

## 我明明已登录，为什么还提示登录？

工具的浏览器与日常 Edge、Chrome、Codex 内置浏览器使用不同会话。请在**点击开始后工具打开的抖音窗口**登录。完成后程序会自动恢复，无需点击继续。

如果仍无法读取，查看界面的具体原因：可能是验证、作品权限、网络或网页结构变化，不能仅凭“已登录”断定一定能读取。超过本次运行时限后任务已经结束，需要重新开始；再次开始前可以调大时限。

## 一定需要登录吗？未登录能不能查？

两种模式都会先尝试读取。平台允许当前会话访问的内容可以检查；页面明确要求登录时，需要本人登录才能继续。工具不绕过登录、验证码、私密权限，也不能承诺未登录获取全部评论。

## 为什么需要我处理验证码？不是全自动吗？

作品打开、滚动、回复展开、加载等待和重试由程序自动处理。平台要求本人完成的登录或验证仍需你操作，完成后程序自动继续。持续验证或访问受限时，已有结果会保留，不能把受限状态解释成“没有评论”。

## 为什么楼中楼是 0 条？

评论总数超过“全量检索阈值”时，程序只查一级评论，默认阈值为 100 条。也可能作品本身没有回复，或回复尚未加载。以界面显示的范围为准。

如果要在较大的评论区检查楼中楼，可以将阈值提高后重新开始，但耗时和检查数量也会增加，且仍受时限、条数上限及平台开放范围约束。

## 为什么读到上限就结束，或者数量略超过上限？

上限用于限制本次运行规模，达到后自动结束并保留结果。评论以整页返回，例如上限 100 条可能在收到一整页后显示 105 条。上限可以在“检查限制”里调整；这不代表已把全部评论读完。

## 为什么网页显示的总评论数和读到的数量不同？

页面计数、一级评论、楼中楼的统计范围可能不同，评论也会新增或删除；有些内容不向当前会话返回。工具会核验分页和已知数量，存在缺页、冲突等情况时保留“未完成”，不会仅凭滚动到底就宣称完整。

## “检查未完成”是不是没有找到目标？

不是。它表示无法证明选定范围已经查完。即使已经找到评论，也可能同时显示未完成覆盖。只有范围完成且目标身份可核验，才能给出该范围内的未找到结论；只查一级评论时无法排除目标在楼中楼中留言。

## 只给昵称、主页或者抖音号，能查到他在所有视频下的评论吗？

不能。本项目需要指定作品，并只检查该作品。昵称可能重名，不能用于确定作者；建议填写完整个人主页链接，或者填写可核验的抖音号。目标主页的分享短链接暂不支持。

## 支持情感分析、批量作品或手机运行吗？

当前没有内置情感分析，也没有批量作品队列或手机应用。导出的命中结果可在你有权处理的范围内另行分析。把代码上传到 GitHub 后，仍需在本机安装运行；GitHub Pages 不能运行本项目的 Node.js 服务和浏览器扫描器。

## 数据会传到哪里？能否清除登录状态？

检索浏览器会访问抖音网站，工具不调用 AI 服务。登录状态及最近任务保存在项目 `.local` 目录中，不会随正常 Git 提交上传。

如需清除本工具保存的登录，应先正常关闭工具服务和检索浏览器，再自行移走或删除 `.local/browser/`。这会影响下次登录；`.local/last-job.json` 是独立的最近任务记录。删除前先保存自己仍需要的数据。切勿把这些文件作为排障附件公开。

## 如何反馈问题？

到仓库的 [Issues](https://github.com/howaway-1/douyin-comment-finder/issues) 使用中文“问题反馈”模板，说明版本、操作系统、Node.js 版本、浏览器、会话模式、限制设置和复现步骤。只提供必要且已去除个人信息的错误信息，不要提供密码、验证码、Cookie 或 `.local` 文件夹。

真实页面的已验证范围见 [验证记录](../VALIDATION.md)。平台网页和访问策略可能变化，测试通过不代表今后所有作品都能检查成功。
