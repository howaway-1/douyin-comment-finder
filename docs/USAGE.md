# 详细使用说明

[返回项目首页](../README.md) · [常见问题](FAQ.md)

## 1. 安装并启动

推荐使用 Windows 10 / 11，安装 Node.js 20 或更新版本，以及 Edge 或 Chrome。新安装 Node.js 时，请从[官网](https://nodejs.org/zh-cn/download)选择仍受支持的 LTS 版本，并保留 npm 组件。

1. [下载项目 ZIP](https://github.com/howaway-1/douyin-comment-finder/archive/refs/heads/main.zip)，完整解压到自己有读写权限的文件夹。
2. 双击 `Install.cmd`，等待出现 `Installation complete`。首次安装需要联网。
3. 双击 `Start.cmd`，浏览器会打开 `http://127.0.0.1:8765/`。
4. 之后日常使用只需要运行 `Start.cmd`。不要在压缩包内直接运行。

如果没有系统浏览器，在项目目录的终端执行 `npx.cmd playwright install chromium`。运行命令前应先完成依赖安装。

也可以在项目目录执行 `npm.cmd ci`、`npm.cmd start`，再手动打开本地地址。以命令行方式启动时，需保持终端运行。macOS / Linux 可使用 `npm ci` 和 `npm start`，但当前完整页面验证以 Windows 为主，一键脚本不适用于这些系统。

## 2. 填写作品链接和目标账号

每次检查一条作品、一个目标账号。支持以下形式；其中占位文字应替换成真实值：

| 输入类型 | 格式示意 |
| --- | --- |
| 视频 | `https://www.douyin.com/video/作品数字ID` |
| 图文 | `https://www.douyin.com/note/作品数字ID` |
| 主页中打开的作品 | `https://www.douyin.com/user/主页标识?modal_id=作品数字ID` |
| 分享短链接 | `https://v.douyin.com/分享码/`，也可粘贴含此链接的分享文字 |
| 目标个人主页 | `https://www.douyin.com/user/完整主页标识` |
| 目标抖音号 | 对方主页显示的抖音号 |

作品栏不能只填一个不含具体作品信息的用户主页。目标账号栏优先填完整个人主页链接；昵称不是唯一标识，目标主页分享短链接暂不支持。抖音号需要通过评论数据或账号搜索核验，搜索失败时可能无法确认完整的未命中结论。

这些格式只是说明，不是可运行的测试账号或作品。

## 3. 选择浏览器会话

| 模式 | 行为 |
| --- | --- |
| 本工具已有会话 | 复用工具自己的浏览器配置，可保存本次登录供下次使用；也可以在未登录状态尝试 |
| 未登录临时会话 | 每次从新的临时会话开始，关闭后不保留浏览器登录状态；本次任务结果仍保存到本地 |

工具使用独立浏览器配置，不会读取日常浏览器的登录状态。请在点击“开始检查”后打开的抖音窗口中登录。无需把密码、验证码或 Cookie 填到本工具中。

如平台要求登录或验证，请在该窗口本人完成。程序会检测页面变化并自动回到原作品继续检查，无需点击继续按钮。平台是否允许访问由页面实际状态决定；等待期间运行时限仍在计时。

## 4. 设置检查限制

| 设置 | 默认值 | 可设置范围 | 作用 |
| --- | --- | --- | --- |
| 最长运行时间 | 10 分钟 | 1–30 分钟 | 包含启动、加载、登录等待及重试；达到后保留已有结果 |
| 最多检查评论 | 2,000 条 | 100–10,000 条 | 限制本次检查规模；全量模式统计一级与回复，仅一级模式统计一级 |
| 全量检索阈值 | 100 条 | 0–10,000 条 | 已知总数不超过阈值时检查楼中楼；超过时只查一级评论 |

首次打开时使用默认值，之后页面会回填最近一次任务的设置。每次开始前可以修改。

评论数量尚不明确时，先读取一级评论，不急于展开楼中楼。全量模式先推进一级评论，再检查需要展开的回复；父评论不是目标账号，也会检查其回复。超过阈值后，本轮不主动展开楼中楼，报告会明确标注范围。设为 0 可优先只查一级评论。

数据以整页返回，读取数量可能略超过设置的条数上限。若小评论区的一条响应已内嵌全部回复，只有数量和标识通过核验后才会认定该回复线程完成。

## 5. 查看并导出结果

- **找到**：已经确认至少一条目标账号评论。是否查完剩余范围，要另外看覆盖状态。
- **已检查完但未找到**：选定范围的分页、数量及作者核验符合完成条件，但未匹配到目标。“仅一级评论”下的未找到不包含楼中楼。
- **检查未完成**：已达到限制、手动停止、页面不可访问、加载失败、分页缺失或账号无法核验等。不能据此断定目标没有评论。

检查结束后可导出 CSV 或 JSON，即使没有命中也可以导出。导出内容为目标命中的评论及必要检查信息，并非整个评论区备份。

CSV 适合用表格软件查看，含 UTF-8 标记和公式注入防护。JSON 保留更完整的范围和诊断信息：

| 字段 | 含义 |
| --- | --- |
| `verdict` | `found` 找到、`not_found` 选定范围内未找到、`incomplete` 未完成 |
| `complete` / `coverage.scopeComplete` | 本次选定范围是否通过完整性核验 |
| `coverage.scope` | `all` 一级及楼中楼、`main_only` 仅一级、`pending` 尚未确定 |
| `coverage.allCommentsComplete` | 一级与楼中楼是否均完成；仅一级模式不能把它视为全量完成 |
| `matches` | 命中评论，包含正文、时间、作者及作品标识等 |
| `parentId` | 非空时为楼中楼回复所对应的父评论标识 |

页面显示的是本机时区下的时间；JSON 的评论时间字段 `time` 通常为 Unix 秒时间戳。

## 6. 停止、关闭与更新

运行中点击“停止”即可结束本次任务并保留已有结果。关闭作品浏览器会提前结束检索。关闭本地网页标签页不等于关闭后台服务。

如果通过终端执行 `npm.cmd start`，可在该终端按 `Ctrl+C` 关闭服务。通过 `Start.cmd` 启动时，可在 PowerShell 执行以下命令正常关闭服务和检索浏览器：

```powershell
Invoke-RestMethod -Uri http://127.0.0.1:8765/api/shutdown -Method Post -ContentType application/json -Body '{}'
```

更换过端口时，请把命令中的端口改成当前端口。重启后可以查看上次保存的结果，但不会自动接着扫描已中断任务。

更新前先停止检索、导出需要保留的报告并正常关闭服务，再解压新版。若要保留工具自己的登录状态，可在本机保管原有 `.local` 目录；不要上传或分享该目录。新的项目副本需要重新运行 `Install.cmd`。

## 7. 本地数据

`.local/browser/` 保存已有会话的浏览器配置，`.local/last-job.json` 保存最近任务，`.local/` 中还可能有启动日志。导出文件保存到浏览器下载位置。

源码仓库已忽略这些本地记录，但将整个文件夹手动压缩或上传时仍需自己检查。反馈问题时只提供必要且已去除个人信息的错误说明。工具没有内置情感分析，也不会把评论发给 AI 服务。
